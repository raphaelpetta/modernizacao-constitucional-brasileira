# Módulos de pesquisa

O catálogo possui 15 módulos de M00 a M14, definidos por **problemas e sistemas funcionais**, e não pelos títulos do anteprojeto de 2026. Podem ser reconfigurados após justificação e registro de impacto. Cada módulo será subdividido em sessões como M00.01, M00.02 etc. Não criar dossiê completo sem pesquisa realizada nem declarar cobertura exaustiva a partir de um catálogo preliminar.
