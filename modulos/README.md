# Dossiês modulares

Criar diretório `modulos/Mxx-nome/` somente ao começar estudo efetivo; usar `modelos/DOSSIE_MODULO.md`. Distinguir investigação de um módulo, sessões especializadas e decisões transversais. Pesquisa não altera o catálogo nem as escolhas constitucionais sem integração formal. Módulos M00–M14 começam PLANEJADO.
